PERSONAL WEBSITE
================

Pages:
1. index.html      - Home
2. about.html      - About Me
3. skills.html     - Skills
4. projects.html   - Projects
5. contact.html    - Contact

Folders:
- css/style.css
- js/script.js

HOW TO EDIT:
1. Open the files in VS Code or another code editor.
2. Replace "your-email@example.com" in contact.html with your preferred email.
3. Change the project descriptions if needed.
4. If you want a profile photo, replace the JM circle in the HTML with an <img> element.

FREE HOSTING:
This website can be uploaded to GitHub Pages. After uploading the files to a GitHub repository, enable Pages under Settings > Pages and select the main branch/root folder.

IMPORTANT:
The contact form is a demonstration only. It does not send real email.
Bootstrap is loaded through its CDN.
